### CIDRは、組織全体で重複させない

**VPCのアドレスは、作った後から自由には変えられません。**

VPCのプライマリCIDR（作成時に指定した範囲）は後から変更できません。追加のCIDRを関連付けることはできますが、元の範囲はそのまま残ります。また、CIDRが重複するVPCどうしはPeeringでつなげません。

アカウント、Region、オンプレミス、VPN先を含めた全体のアドレス計画を先に作ります。割り当てはIPAM（IPアドレス管理）ツールや管理表で一元管理します（第2章）。AZや層の追加に備え、サブネットの空き範囲も残しておきます。

### AZ障害を前提に配置する

サブネット、インスタンス、ALBのターゲットは、複数のAZに分けて置きます。

NAT Gatewayも、本文の推奨構成どおりAZごとに作ります。各AZのプライベートサブネットは、同じAZのNAT Gatewayへ向けます。こうすると、1つのAZの障害が、ほかのAZの外向き通信を止めません。

AZをまたぐ通信にはデータ転送料金がかかる場合があることも、経路設計の判断材料になります。

### Security Groupは層ごとに参照で組む

本文の「alb-sg → app-sg → db-sg」のように、前の層のSGだけを送信元として許可します。IPアドレスに依存しない、最小限の許可になります。

管理用のSSH（22番）やRDP（3389番）を 0.0.0.0/0 に開けるのは避けます。送信元を絞るか、インバウンドのポートを開けずに接続できる仕組み（AWS Systems Manager Session Managerなど）を検討します。

NACLは、特定の範囲を広く拒否する補助的な防御として使うのが一般的です。

### 障害と侵害の範囲を区切る

本番と開発は、VPCやアカウントを分けます。必要な組み合わせだけを、PeeringやTransit Gatewayでつなぎます。

ルートテーブルは用途ごとに分けます。メインルートテーブルには、インターネットへの経路を入れないでおきます。関連付けを忘れた新しいサブネットが、意図せずパブリックになるのを防げます。

### 変更はIaCで、差分を見てから適用する

SGやルートテーブルの変更は、適用するとすぐに有効になります。

IaC（Infrastructure as Code：構成をコードで管理する方法。TerraformやCloudFormationなど）で管理し、変更前に差分をレビューします。戻すときは、以前の版を適用します（第12章）。

また、SGのルールを削除しても、追跡中の既存の接続はすぐには切れない場合があります。「ルールを消したのにまだつながる」ことがあると知っておきます。

### フローログとAPIの記録を残す

VPC Flow Logsは、ネットワークインターフェースを通った通信の、送信元・宛先・ポート・許可（ACCEPT）か拒否（REJECT）かなどを記録します。ペイロード（中身）は含まれません。

誰がいつSGやルートを変えたかは、CloudTrail（AWSの操作の記録）で追えます。障害時には、通信の記録と変更の記録を時刻で突き合わせられます。

### 料金も設計の一部

NAT Gatewayは、時間料金に加えて、処理したデータ量でも課金されます。S3やDynamoDBへの大量の通信は、Gateway型エンドポイントに切り替えると、NAT経由のデータ処理料金を避けられます。

パブリックIPv4アドレスにも料金がかかります。本当に公開が必要なリソースだけに付けます。

### 切り分けは、経路とフィルタを往復で確認する

「つながらない」ときは、本文の「行きと帰りでたどる」の順に確かめます。

```text
ルートテーブル → IGW / NAT Gateway → NACL（インバウンドとアウトバウンド）→ SG → OSの待ち受け
```

NACLはステートレスなので、戻りのエフェメラルポートの許可漏れが典型的な原因です。

Reachability Analyzerで設定上の経路を確認し、Flow LogsのREJECTで実際に拒否された通信を確認します。推測ではなく根拠で説明できます。なお、このシミュレータの到達性分析は、実際のReachability Analyzerとは表示と対象範囲が異なります。

### まとめ

- VPCのCIDRは後から変えにくい。組織全体で重複しない計画を先に作る。
- NAT Gatewayを含め、AZごとに配置してAZ障害に備える。
- SGは前の層のSGを参照して最小限に許可し、管理ポートを全開放しない。
- 変更はIaCで差分をレビューし、Flow LogsとCloudTrailで記録を残す。
- 切り分けは、経路・NACL・SG・待ち受けを行きと帰りの両方で確かめる。
