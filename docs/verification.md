見つけて直した不具合（主なもの。それぞれ回帰テストあり）:

- **UI**: 画面のどこでもBackspace / Deleteで、Terminalの送信元として選ばれている機器が削除されていた。Analyzerのラボ間の移動でアプリ全体が落ちていた。教材の「テンプレートを開く」リンクが、確認なしで編集中の構成を上書きしていた。ラボをすばやく切り替えると、前のラボの構成が次のラボの保存データに書き込まれていた。Terraformの編集が、300ms以内に画面を切り替えると失われていた。同じ名前で保存すると、更新ではなく重複した構成ができていた。確認ダイアログがフォーカスを受け取らず、Escで閉じなかった。Terraform Labの到達性分析の結果が、入力のたびに消えていた。教材中のシミュレーション内のURL（`http://198.51.100.80/` など）が、実際のインターネットへのリンクになっていた。
- **Network Core / CLI**: Next Hopを解決できない経路が優先されて通信が止まっていた（次の候補へフォールバックするように修正）。Line protocolがDownのサブネットをOSPFが広告し続けていた。OSPF / BGPで学習した経路の上のトンネルがUpにならなかった。FIN後のconntrackがESTABLISHEDに戻っていた。キャプチャフィルタで `and` が `or` より強く結合していた。GREのキャプチャが内側のヘッダーでフィルタされていた。`iptables -F` が常にエラーになっていた。interfaceモードの `ip nat inside source …` がインターフェースの設定を変えていた。ACLモードからグローバル設定のコマンドに戻れなかった。引数の不足で JavaScript のエラーメッセージがそのまま表示されていた。
- **AWS / Terraform**: ピアリングの戻りの経路を検査していなかった（推移的な経路が到達可能と判定されていた）。セキュリティグループなしのALBがSGの判定を素通りしていた。壊れた参照を含む設計で分析ボタンが無反応になっていた。モジュールがあると `terraform destroy` でリソースが残っていた。関数や .tfvars のエラーでコマンドが無反応になっていた。承認待ちのapplyが、コード変更やstate lockのあとでも実行されていた。
- **ラボ**: 13のラボで、要件を満たさない近道（Firewallを無効化・すべて許可のルール・余分なポートの公開など）でも合格できていた。linux-masteryで自動診断が答えを表示していた。`dns-ts-01` が `linux-ts-06` と同じ演習だったため、「再帰リゾルバではなく権威サーバーに問い合わせている」障害に変更した。
- **教材**: SYNの再送回数、Ackの説明、IPヘッダーのフィールド順、ACLを適用するインターフェース、PTRの例の名前を実装・実機に合わせて修正した。

## この検証で見つけて直した不具合

- シミュレータのキャンバスに残っていた`min-width: 1080px`のため、React Flowの表示領域がInspectorの下まで広がり、fitViewしても機器が隠れていた。
- 1ポートの機器向けの「ポートを対向側へ向ける」処理が複数ポートの機器にも効き、port 0がport 1と同じ位置に重なってドラッグで配線できなかった。
- 全体の`input`スタイルがチェックボックスにも効き、大きな枠で表示されていた。キャンバス凡例のチェックボックスがクリックできなかった。
- IOS風CLIのサブモード（interface / router / vlan）で、認識できないコマンドが何も表示されずに無視されていた（`interface g0/2` で別のポートへ移れず、直前のポートに設定し続けてしまう）。実機のIOSと同じく、サブモードでもグローバル設定のコマンドを実行し、それ以外は `Invalid input` と使えるコマンドを表示するよう修正した。
- Packet Analyzerのラボ画面が、スマートフォン幅で横にはみ出していた（グリッドの列が表の幅に引き伸ばされていた）。
- AWS VPC Designer の図で、ロードバランサーがAZの見出しに、リソースがサブネットの見出しに重なり、線とそのラベル（0.0.0.0/0、:8080）が文字の上を通っていた。固定座標のレイアウトを、実寸から下から上へ大きさを決めるレイアウトに作り直し、見出しを線より上に描く別ノードにした（`awsLayout.ts`。全シナリオ・全AWSラボ・Terraformラボの結果で重なりがないことをユニットテストで保証）。
- ネットワーク図で、テンプレートやラボの初期座標が機器の実寸より詰まっていて重なっていた（DNS・NAT・企業LANなど）。描画後にポートラベルを含む実寸を測って重なりを押し広げ、追加した機器やドラッグで重ねた機器は最寄りの空き位置へ移すようにした（`diagram/overlap.ts`）。
- Terraform Lab でコードエディタが列からはみ出し、右の依存関係グラフを覆っていた。1列のグリッドすべてを `minmax(0,1fr)` にして、幅の広い子要素が隣へはみ出さないようにした。
- 同じページで `?template=` 付きのリンクを開いても、テンプレートが読み込まれなかった。
